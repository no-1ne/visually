## Title

Visually — One Brief, Five Formats with WebMCP

## Description

Visually is a browser-first visual design studio where people and AI agents work on the same editable canvas.

Through 17 typed WebMCP tools, an agent can turn one brief into five coordinated campaign formats, propagate semantic brand changes across every page, audit production readiness, and continue with precise element, page, history, and export operations. Every change remains visible, editable, inspectable, and reversible in the normal interface.

The application is built with React, Vite, TypeScript, Konva, Zustand, shadcn/Base UI, browser ML, and FFmpeg/WASM. Rendering and project export stay client-side; the Cloudflare Worker serves the application and supports optional R2 upload flows.

Try Visually: https://visually.deeeplearn.com
Source: https://github.com/no-1ne/visually

Created for The WebMCP Challenge.
